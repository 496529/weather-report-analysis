# weather-report-analysis
"A high-performance Weather Data Analysis & Forecasting Application built with Python, MySQL, Pandas, and Scikit-learn. This full-stack solution analyzes six years of daily weather data (2020–2025) across eight major Indian cities. Beyond professional analytical charting with Matplotlib and Seaborn, the app features a Predictive Analytics Engine powered by Random Forest Regression. It provides long-term daily forecasts for temperature, humidity, and rainfall, enabling data-driven insights and future climate trend projections through an interactive, immersive interface."
